TechStore

Sobre o projeto

A TechStore é um site fictício de uma loja especializada em componentes de computadores, hardware, periféricos e acessórios tecnológicos.

O projeto foi desenvolvido como parte de uma avaliação prática do curso Técnico em Desenvolvimento de Sistemas do SENAI, com o objetivo de aplicar e aprimorar conhecimentos em desenvolvimento web.

Tecnologias utilizadas

- HTML5: estruturação e utilização de elementos semânticos.
- CSS3: estilização, organização visual e personalização das páginas.
- JavaScript: interatividade e manipulação do DOM.
- Git e GitHub: controle de versionamento e armazenamento do projeto.

Funcionalidades

- Menu de navegação entre páginas.
- Página inicial de apresentação da loja.
- Página institucional sobre a empresa.
- Interface de login e cadastro de usuários.
- Interface de recuperação de senha.
- Alternância entre formulários sem recarregar a página.

Objetivos do projeto

- Aplicar conceitos de HTML semântico.
- Desenvolver interfaces organizadas e intuitivas.
- Aprimorar conhecimentos em estilização com CSS.
- Desenvolver funcionalidades utilizando JavaScript.
- Praticar o controle de versionamento com Git e GitHub.
- Consolidar conhecimentos em desenvolvimento front-end.

Como executar

1. Clone ou baixe o repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Execute o arquivo "index.html" no navegador ou utilize a extensão Live Server.
